# Receiptly — Free Receipt Generator

Modern open-source static receipt generator PWA. No account, database, backend or subscription required.

Features: logo upload, multiple items, tax/discount, GHS/USD/GBP/EUR/NGN, QR code, print, PDF, PWA install, responsive UI, GitHub/Cloudflare compatible.

## Deploy
Push the folder to GitHub and enable GitHub Pages, or connect the repository to Cloudflare Pages. No build command is required.

## Rebrand
Change the name/title in `index.html`, `manifest.webmanifest`, and colors in `styles.css`.

## QR note
The QR code stores receipt details directly in the QR payload. There is no server-side verification database, keeping the project free and static.
